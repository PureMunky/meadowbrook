# 🌻 Meadowbrook Farm

A slow, cozy farming game in a single HTML file. No timers to beat, and nothing ever withers.

**Play:** https://puremunky.github.io/meadowbrook/

## How to play
- **Tap a plot** to do the next natural thing: till → plant your chosen seed → water → harvest.
- **Drag** across plots to work a whole row in one stroke.
- Watered plants grow one stage overnight. Rainy days water everything for you.
- **Sleep** whenever you like; a day lasts about three minutes.
- Harvests earn coins and XP. New seeds unlock as you level up (9 crops, some regrow).
- The shop sells more land, sprinklers, and hens that lay eggs each morning.
- 🎵 turns on gentle generative music (Web Audio, no assets).

Progress saves to `localStorage` in your browser.

## Tech
One self-contained `index.html`: vanilla JS, CSS, emoji art, and Web Audio. No build step, served from GitHub Pages.
